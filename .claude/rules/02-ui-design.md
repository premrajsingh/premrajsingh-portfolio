# UI design (future portfolio work)

Apply only when implementing or refining UI after explicit instruction.

- Aim for a clean, premium visual style with strong typography and consistent spacing.
- Centralize design tokens (colors, type, spacing, radii) rather than scattering magic values.
- Build responsive layouts; ensure good contrast.
- Use subtle borders and gradients; keep glass effects controlled.
- Avoid excessive neon, generic template looks, and distracting effects.
- Never invent fake content; use clearly marked placeholders when data is missing.
- Do not redesign the existing UI unless the user requests it.
