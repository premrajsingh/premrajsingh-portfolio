# Accessibility

- Use semantic HTML and a correct heading hierarchy.
- Ensure full keyboard navigation and visible focus states.
- Use accessible buttons/links with proper labels.
- Maintain sufficient contrast; support screen readers.
- Honor `prefers-reduced-motion`; avoid keyboard traps.
- Provide touch-friendly controls and WebGL fallback content.
