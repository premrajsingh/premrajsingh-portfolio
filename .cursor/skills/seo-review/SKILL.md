# SEO review

## When to use

Metadata, Open Graph, semantic structure, crawler configuration.

## Inspect first

- `index.html` title/description
- Heading hierarchy in the app
- Public assets and social preview needs

## Approach

1. Accurate title and meta description from real content only.
2. Semantic landmarks and heading order.
3. Canonical/public URL via env placeholder when known.
4. Add sitemap/robots only when deployment URL is real.

## Avoid

- Fabricated keywords, metrics, or awards
- Duplicate titles/descriptions

## Verify

- View source / Lighthouse SEO category when available
